# ReportGaraCalcio

Applicazione mobile-first per la compilazione e l'invio rapido dei report gara.

## Obiettivo
Rendere l'app **più veloce e intuitiva possibile** su smartphone, con attenzione a:

- tempi di caricamento rapidi;
- flussi principali completabili in pochi tap;
- robustezza in connessione instabile;
- usabilità elevata durante l'uso sul campo.
